지도 SDK 및 API 보안 키 설정 가이드

브라우저용 JS 키 vs 서버용 비밀 키 구분

카카오 지도 SDK의 JavaScript 키는 브라우저 클라이언트 식별용입니다. 서버 API Secret 키나 사용자 개인정보는 절대로 클라이언트 프론트엔드 코드에 노출해서는 안 됩니다.

1. Kakao Map JavaScript 키 적용 방법

  1. 카카오 개발자 센터에서 앱 생성 후 JavaScript 키 복사
  2. HTML 상단 주석 처리된 SDK 스크립트의 YOUR_KAKAO_JAVASCRIPT_KEY 부분을 실제 발급된 키로 변경

2. 카카오 콘솔 웹 도메인 허용 설정

카카오 개발자 콘솔 [플랫폼] - [Web] 항목에 개발 중인 서비스 URL (예: http://localhost:3000)을 등록해야 오직 허용된 서비스 도메인에서만 지도가 정상 동작합니다.
